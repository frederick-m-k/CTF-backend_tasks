About ROT13

ROT13 (Rotate by 13) is a simple letter substitution cipher that replaces a letter with the 13th letter after it in the alphabet. It is a special case of the Caesar cipher.

How to Decrypt

Either manually rotate each letter by 13 or use a website to decipher it.

Hint: Numbers and symbols (like -, 0, 1, 3) are not affected by ROT13. Only letters A-Z and a-z change. The decrypted message is the flag!
